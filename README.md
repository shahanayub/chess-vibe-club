# Chess Web App

A lightweight 2-player local (same device) chess web application built with React, Vite, Tailwind CSS, chess.js, and react-chessboard.

## Setup & Running
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```
